# 任务流管理系统 M1 — 用户手册

> 适用版本: feat/task-flow-m1 分支, commit 687709f
> 更新日期: 2026-07-17

## 1. 登录

- 访问 http://127.0.0.1:5050/login
- 选择员工身份 (无需密码)
- 顶栏显示当前操作员 + 退出按钮

## 2. 建单 (上传图片 OCR 识别)

- 任务流 → ➕ 建单 (或直接访问 /tasks/new)
- 上传单据图片 (支持粘贴 / 选择 / 拖拽)
- 引擎默认 PaddleOCR + DeepSeek (离线 + 在线组合)
- 识别后: 客户名称 / 单据号 / 明细自动回填到表单
- 点"创建任务" → 跳到详情页

## 3. 任务列表

- 任务流 → 📋 任务列表
- tab 切换: 全部 / 待接单 / 进行中 / 已完成 / 已退单
- 点任务进详情

## 4. 任务详情

- 顶部 7 阶段进度条: 准备中 → 已装货 → 已点数 → 已到达 → 已卸货 → 已完成 (或 已拒收/已作废)
- 头部: 客户 / 单据号 / 司机 / 车辆
- 证据图: 各阶段上传的照片
- 商品明细表
- 事件历史 (时间线)

## 5. 状态推进 (T11 起, M2 完整)

- 各角色 (司机/调度/文员) 根据权限推进状态
- 装车照 → 已装货 / 点数照 → 已点数 / 卸货照 → 已卸货 / 签收单 → 已完成

## 6. 异常处理

- 司机退单: 上传退单照 + 点"司机退单" (回退到准备中)
- 任务作废: 调度/文员在准备中状态可作废
- 整单退回: 上传退货照 → 自动生成退货任务 (数量负)

## 7. 人员 / 车辆管理

- 任务流 → 👥 人员档案: 增删改 + 角色过滤 + 车辆绑定
- 任务流 → 🚐 车辆档案: 增删改 + 状态过滤

## 8. 打码抢单池 (M1 占位)

- 任务流 → 💻 打码抢单池
- M1 只显示待打码任务
- 抢单/完成/释放 M2 接

## 9. 已知限制 (M1)

- 单人使用 (没有密码/没有并发安全)
- 打码抢单池是占位, 不能真抢
- 退货/换货 UI 文案 M1 统一一套, M2 适配
